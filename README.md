# Library App
A responsive, dynamic library tracker built with Vanilla JavaScript that allows users to add, remove, and toggle the read status of books.

---

## 🎯 Project Goals
- Construct SVG elements dynamically using DOM methods without `innerHTML`
- Practice Object Constructors and Prototype methods
- Organize application state cleanly using Objects and Arrays

## ✨ Features
- Add and remove books with title, author, page count, and read status
- Interactive toggle switch for book read status on each card
- Native HTML `<dialog>` element for modal inputs
- Dynamic SVG icon generation powered by Vanilla JS
